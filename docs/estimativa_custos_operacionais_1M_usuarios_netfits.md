## 📌 1. Validação & Ajuste com o Modelo Cloud v2.4

A nova estimativa de infraestrutura em nuvem (**Modelo v2.4**) dimensiona a plataforma para alta disponibilidade com suporte a **25.000 usuários simultâneos em pico**, banco relacional de ledger imutável (**Cloud Spanner/Postgres HA**), mensageria transacional por **WhatsApp API (Twilio)** e APIs de validação cadastral automática em tempo real (**Receita Federal / CRM / CREF / CRN**).

### 📐 Principais Ajustes de Infraestrutura (1.000.000 de Usuários / 600.000 MAU):
- **Custo Mensal Cloud Validado (v2.4)**: **US$ 8.000 a US$ 11.200 / mês** (Média de **R$ 48.000,00 / mês** a R$ 5,00/USD).
- **Custo Unitário de Cloud**: **R$ 0,048 / usuário cadastrado / mês** (ou **R$ 0,08 / MAU ativo / mês**).
- **Impacto no Faturamento**: O custo de nuvem representa apenas **1,65% da Receita Bruta Mensal** no marco de 1M de usuários (Receita R$ 2,89M vs Cloud R$ 48k/mês), preservando uma **Margem EBITDA de 41,3%**.

## 🛠️ 4. Detalhamento dos Componentes Cloud v2.4 ($9,600 / mês para 1M Usuários)

1. **Compute & Auto-Scaling Serverless ($2.800 - $3.500/mês)**: Cloud Run / Vercel Enterprise auto-scaling para 25.000 usuários simultâneos em pico.
2. **Banco de Dados & Ledger Imutável ($1.800 - $2.400/mês)**: Cloud Spanner / Postgres HA com Two-Phase Lock transacional para gravação dos pontos `nfs`.
3. **Cache Redis Memorystore ($400 - $600/mês)**: Google Cloud Memorystore 32GB em HA para saldos e sessões.
4. **CDN & Segurança WAF ($800 - $1.200/mês)**: Cloudflare Enterprise WAF contra ataques DDoS e rápida entrega de mídias do Feed.
5. **APIs de Validação Cadastral ($300 - $600/mês — R$ 1.500 a R$ 3.000/mês)**: Validação automática de CNPJ e checagem de órgãos de classe (CRM, CRN, CREF, CREFITO) em `/parceiros`.
6. **Mensageria Transacional WhatsApp API ($1.500 - $2.200/mês)**: Envio de vouchers do Shop e notificações transacionais via Twilio API.
7. **Observabilidade & APM ($400 - $700/mês)**: Datadog + Stackdriver para rastreabilidade de ledger de pontos.
